# Codex Discovery Prompt

```text
CONTRIBUTOR DISCOVERY MODE.

This is discovery only for Briah's Car Rental.

DO NOT modify source code.
DO NOT create migrations.
DO NOT commit.
DO NOT push.
DO NOT open implementation Pull Requests.
DO NOT deploy production.

Use the assigned role/area and relevant installed skills such as agent-browser, webapp-testing, web-design-guidelines, or security-best-practices.

Systematically inspect the assigned surfaces.

For every distinct suspected problem record:
- role;
- page/area;
- expected behavior;
- observed behavior;
- exact reproduction steps;
- safe evidence;
- reproducibility;
- suggested P0-P4 severity;
- potential context/manuscript conflict.

Do not invent fixes.

If expected behavior is unclear, report it as requiring Lead triage.

Avoid uncoordinated production mutations.

Return:
1. surfaces inspected;
2. Findings;
3. evidence;
4. unsafe/unavailable checks;
5. confirmation that no code was changed.
```
