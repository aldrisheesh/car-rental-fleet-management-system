# Codex Discovery Prompt

CONTRIBUTOR DISCOVERY MODE.

Do not modify source code, create migrations, commit, push, open implementation PRs, or deploy production.

Read the contributor's assigned quality-lane instructions first.

Use that quality lens across the entire system. Respect hard scope guardrails.

For every suspected problem record:
- role/page/area;
- expected behavior;
- observed behavior;
- reproduction steps;
- safe evidence;
- reproducibility;
- suggested P0-P4 severity;
- context/manuscript conflict;
- cross-scope handoff if needed.

Do not invent fixes. Avoid uncoordinated production mutations.

Return:
1. surfaces inspected;
2. Findings;
3. cross-scope handoffs;
4. evidence;
5. checks not safely performed;
6. confirmation that no code was changed.
